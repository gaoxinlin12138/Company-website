# 网站内容与管理后台边界

这份文档定义“后台可修改的内容”和“只能由开发人员修改的界面”，是数据库、API 和管理控制台的共同依据。

## 管理原则

- 后台管理业务内容，不管理页面布局。
- 所有公开内容同时保留中文和英文字段。
- 所有列表内容具有草稿、已发布、已归档三种状态。
- 所有可排序内容使用明确的 `sortOrder`，不依赖创建时间隐式排序。
- 图片只保存媒体记录和访问地址，不把二进制内容写进业务表。
- 中文为运营录入主语言；中文新增或变化时由服务端生成英文译文，英文仍允许人工校正，前台不在访问时临时翻译。
- 删除优先采用归档状态；只有确认无引用的内容才永久删除。

## 后台可管理内容

### 产品分类

| 字段 | 说明 |
| --- | --- |
| 中文名 / 英文名 | 分类显示名称 |
| 所属大类 | 卫浴产品、卫浴五金、安装及配件 |
| 上级分类 | 支持二级分类 |
| 封面图 | 分类入口图片 |
| 排序 | 同级分类显示顺序 |
| 状态 | 草稿、已发布、已归档 |

### 产品

| 字段 | 说明 |
| --- | --- |
| 中文名 / 英文名 | 产品名称 |
| URL 标识 | 产品详情地址使用的唯一 slug |
| 分类 | 关联产品分类 |
| 型号 | 对外展示型号 |
| 中文 / 英文材质 | 产品材质 |
| 中文 / 英文表面处理 | 产品表面工艺 |
| 中文 / 英文简介 | 产品列表摘要 |
| 封面图和图集 | 列表主图与详情图片 |
| 排序和状态 | 显示顺序、草稿/发布/归档 |

### 新闻

- 分类、中文/英文标题、摘要和正文
- 封面图、发布日期、作者（可选）
- SEO 标题、SEO 描述
- 排序和发布状态

### 案例

- 分类、中文/英文标题、摘要和正文
- 项目类型、地点、供应产品
- 封面图与案例图集
- SEO 信息、排序和发布状态

### 首页

- 轮播图：分类文字、主标题、强调文字、说明、图片、按钮、三个特征标签、排序和状态
- 产品入口：名称、说明、图片、跳转地址、排序和状态
- 推荐产品：关联已有产品，不单独重复保存产品资料

### 关于我们

- 公司介绍导语，以及可排序的中英文文字块和图片块；运营人员可以调整图文出现顺序，但不开放页面栅格、颜色与响应式规则
- 检测报告名称、封面、文件、排序和状态
- 常见问题中英文问题与答案

### 联系方式与站点设置

- 电话、邮箱、微信、WhatsApp、地址、工作时间
- Logo、默认 SEO、公司中英文名称
- 产品电子图册文件及版本说明

### 询价

- 姓名、公司、电话、邮箱
- 感兴趣的产品和需求说明
- 来源页面、提交时间
- 新询价、处理中、已关闭状态
- 内部备注（不在前台显示）

## 不开放给后台的内容

以下内容继续由前端代码控制：

- 导航栏的整体结构和响应式行为
- 页面栅格、区块顺序和卡片结构
- 品牌颜色、字号、间距、阴影
- 动画参数和交互方式
- 表单校验规则与权限策略
- API 地址、数据库结构和部署配置

这样可以避免运营人员误操作导致页面布局损坏。

## 管理员角色

第一版只设置一个 `admin` 角色，具有内容管理和询价查看权限。后续确有多人协作需求时，再增加编辑、审核和只读角色，第一版不提前制造复杂权限。

## 当前实现状态

- 首页已经统一为 Nuxt 页面，并通过 `/api/content/home` 读取结构化首页内容。
- `/api/inquiries` 已提供询价输入校验，并通过 MySQL 连接池写入 `inquiries` 表；连接地址由 `DATABASE_URL` 配置。
- `prisma/schema.prisma` 记录产品、分类、文章、案例、媒体、询价、站点设置和管理员模型，当前 API 使用 `mysql2` 执行查询。
- 管理控制台已开放：`/admin` 提供总览、产品、新闻、案例、首页内容和询价管理，并支持列表、筛选、发布状态、排序、编辑和媒体上传等已实现功能。
